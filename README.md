# Employee RAG System

A learning project: a RAG system that answers questions about team members from an Excel sheet.

👉 **See [PROJECT.md](./PROJECT.md)** for the full plan, progress tracker, and session context.

## Quick start (once built)
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python main.py
```

The CLI entrypoint also still works as `python src/main.py`, but `python main.py`
is the simplest command to run from the repository root.
